# hey, welcome to my portfolio! 

hi! i'm sabhira, and this is my little corner of the internet

this repository contains my personal portfolio website, where i introduce myself, share a few of my interests, and put some of the things i enjoy in one place. it's a simple project, but it's also one of my steps into learning web development and building things on my own

✦ what's inside?

the website is a small introduction to who i am and what i like.

- a little about me — a short introduction and some information about myself
- my interests — a glimpse into my interest in coding, astronomy, and rhythm games.
- somewhere to start — a link to Hack Club, a community for people who enjoy making things with code

✦ built with

here are the technologies i used to build this project:

- HTML5 — for the structure and content of the website.
- Tailwind CSS — for styling, layout, spacing, and colors.
- Tailwind CDN — to use Tailwind CSS directly without a separate build setup.

✦ running locally

want to see the website on your own device? here's how!

1. Clone this repository

```bash
git clone https://github.com/i1kwm/my-portofolio.git
```

2. Navigate into the project folder

```bash
cd my-portofolio
```
3. Open the website
Since this project uses plain HTML, there is no need to install additional dependencies or configure a development server
Simply open `index.html` in your browser
Alternatively, you can use the Live Server extension in VS Code to preview the website while making changes
Note: An internet connection is needed for Tailwind CSS to load through its CDN
